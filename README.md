## Focus

**Cloud GRC as code.** Controls mapped to NIST 800-53, ISO 27001, SOC 2, HIPAA and PCI DSS, implemented as policy and Terraform rather than spreadsheets.

**AI governance.** NIST AI RMF, ISO 42001, EU AI Act readiness, and security for LLM, RAG and agent (MCP) workloads.

**Secure platform foundations.** GCP landing zones on Cloud Foundation Fabric, DevSecOps pipelines, Kubernetes hardening.

**Architecture review boards.** TRB and ARB governance, exception handling, and the tooling behind them.
